# Security Policy

This is an authentication library — please report vulnerabilities privately rather than opening a public issue, so a fix can ship before the details are public.

## Reporting

Email **4037135+tomekmakuch@users.noreply.github.com** with:

- A description of the issue and its potential impact
- Steps to reproduce (a minimal example, if possible)

You should get an acknowledgement within a few days. Once a fix is ready, it'll ship in a new release and the issue will be disclosed, crediting you unless you'd prefer otherwise.

## Supported Versions

Only the latest released version is supported. There's no long-term-support branch at this stage.
